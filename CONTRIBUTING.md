# Contributing

Contributions are welcome: issues and pull requests both.

- To build and test, follow [Get started](docs/tutorials/getting-started.md).
  The rest of the documentation is indexed in [docs/README.md](docs/README.md).
- Before you open a pull request, run `./check.sh quick` and make sure
  it passes. CI runs the full suite.
- Documentation follows [Diátaxis](https://diataxis.fr/) (tutorials,
  how-to guides, reference and explanation, each in its own folder
  under `docs/`) and the
  [Google developer documentation style guide](https://developers.google.com/style).
  Each fact is written down in one place, and other pages link to it;
  a value that lives in code is named, not copied. Notable changes go in
  [CHANGELOG.md](CHANGELOG.md), as
  [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) describes.
- Report a security problem privately, as [SECURITY.md](SECURITY.md)
  describes, not in an issue.
- Everyone here follows the [code of conduct](CODE_OF_CONDUCT.md).
