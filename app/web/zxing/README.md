# ZXing

`zxing-library-0.23.0.min.js` is `umd/index.min.js` from the npm package
[`@zxing/library`](https://www.npmjs.com/package/@zxing/library) 0.23.0,
unchanged, and `LICENSE` is that package's (Apache-2.0). The app's QR
scanner loads it from here rather than from a CDN
(`app/lib/ui/scan_setup_web.dart`).
